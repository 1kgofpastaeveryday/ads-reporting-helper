Privacy Policy — Ads Reporting Helper

Last updated: 2026-11-24

Who uses this tool

Ads Reporting Helper is used only by its developer, with the developer's own Google account. It is not offered to other users.

Data accessed

With the developer's authorization, the tool requests read-only access to Google Analytics reports and access to the Google Ads API. It reads aggregated performance data such as impressions, clicks, cost, conversions, search terms and page-level event counts.

How the data is used

The data is used only to review advertising performance and prepare reports for the accounts the developer is authorized to manage. It is not sold, not used for advertising profiles, and not shared with third parties except as needed to provide those reports to the account owner.

Storage and deletion

Report data is stored on the developer's own computer and is deleted when it is no longer needed for that work. OAuth credentials are stored locally and can be revoked at any time from Google Account permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent through the developer's GitHub profile.
